apt 安装也可以使用下载缓存

2 分钟阅读

在 Debian 或 Ubuntu 基础镜像中，可以缓存 apt 下载包和索引。以下是独立示例：

# syntax=docker/dockerfile:1
FROM ubuntu:24.04

# 关闭镜像自带的下载包自动清理，并配置保留下载包。
RUN rm -f /etc/apt/apt.conf.d/docker-clean \
    && echo 'Binary::apt::APT::Keep-Downloaded-Packages "true";' \
       > /etc/apt/apt.conf.d/keep-cache

# 缓存下载包和索引；加锁避免并发构建同时修改 apt 数据。
RUN --mount=type=cache,target=/var/cache/apt,sharing=locked \
    --mount=type=cache,target=/var/lib/apt,sharing=locked \
    apt-get update \
    && apt-get install -y --no-install-recommends curl

apt 需要独占访问相关缓存，因此这里使用 sharing=locked。不要在这个缓存安装步骤中再运行 apt-get clean，否则会清掉准备复用的下载包。逻辑与 npm 相同：整步命中时跳过安装；步骤需要重跑时，再利用下载缓存。apt 官方示例
